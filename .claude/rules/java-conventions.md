# Java conventions

- Base package is `ua.kpi.blindpig`. Never create a second root package.
- Use **constructor injection** by default with `final` fields. Setter and field injection appear only in the lab-2 DI demo beans (`<domain>/demo/`).
- **Money** is `BigDecimal` with scale 2, and computed amounts use `RoundingMode.HALF_UP`. Never `double` or `float`. Compare with `compareTo`, not `equals`.
- Time is `LocalDateTime`. Inject a `java.time.Clock` instead of calling `LocalDateTime.now()` directly when the logic depends on "now", so tests can use `Clock.fixed`.
- IDs are `Long`, generated by the repository or DB, never by the client. Statuses and types are enums.
- DTOs and requests are `record`s in `<domain>/dto` (contract) or `<domain>/web/**/dto` (web-only). Models are Lombok classes (`@Getter @Setter @NoArgsConstructor @AllArgsConstructor`).
- Errors use exceptions from `ua.kpi.blindpig.common`:
  - `ResourceNotFoundException` → 404: unknown ID or code, or an address belonging to another customer.
  - `InvalidRequestException` → 400: null or blank required input, out-of-range values.
  - `BusinessConflictException` → 409: duplicates, forbidden status transitions, invalid promo, unavailable item or courier.
- `getById`-style methods throw; they never return `null` or `Optional`. Lists are never `null`; return `List.of()`.
- Validate inputs in the service as well (HTML forms bypass `@Valid` on REST), and trim strings before saving.
- Keep names plain (`DiscountServiceImpl`, not `DiscountManagerFactoryImpl`). Comment only what is non-obvious.
